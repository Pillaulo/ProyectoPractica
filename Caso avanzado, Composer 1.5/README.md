# Cuentos Mágicos

Aplicación web de cuentos personalizados con lectura progresiva para apoyo a la lectura infantil.

## Cómo ejecutar

1. **Requisitos:** Node.js 18+ y npm
2. **Setup:** `scripts\setup.bat`
3. **Desarrollo:** `scripts\dev.bat`
4. Abrir **http://localhost:5173** en el navegador
5. **Tests:** `scripts\test.bat`

---

- `setup.bat` — Instala dependencias de backend y frontend
- `dev.bat` — Levanta backend (3000) y frontend (5173) en ventanas separadas
- `test.bat` — Ejecuta los tests del backend
