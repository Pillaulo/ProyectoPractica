# Skill: Checklist para admin de contenido

- Definir claramente los **temas permitidos** y **temas a evitar** (lista de palabras clave).
- Revisar periódicamente cuentos generados marcados como `FLAGGED` o `HIDDEN`.
- Ajustar la plantilla de prompt para:
  - reforzar lenguaje positivo y motivador,
  - limitar longitud según nivel de lectura,
  - controlar aparición de elementos potencialmente sensibles (miedo, monstruos, etc.).
- Comprobar que el JSON devuelto sigue el esquema esperado antes de guardarlo.
- Verificar que las preguntas de comprensión (`comprehension_questions`) son adecuadas al nivel.

Este checklist sirve como guía rápida para la sección de administración.
