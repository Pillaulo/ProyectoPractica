# Skills del proyecto de cuentos

Este directorio está pensado para agrupar **skills, prompts y guías** que usa la aplicación:

- **`groq-prompt.md`**: especificación del JSON esperado del modelo y plantilla de prompt.
- **`admin-checklist.md`**: recordatorios para configurar contenido seguro y adecuado para niños.

Puedes añadir aquí nuevos documentos con patrones de prompts, flujos de moderación o notas pedagógicas para seguir mejorando la generación de cuentos.
